# over_time aggregation function corpus (ticket P5, docs/promql-evaluator-plan.md
# section 8): avg, min, max, sum, count, stddev, stdvar, quantile, present,
# last, absent _over_time, all against
# crates/ravel-promql-difftest/src/generator.rs's fixed dataset. Every offset
# is relative to the dataset's base_ts_ms.
#
# `diff_special_values` (one sample every 30s: 1.5, +Inf, -1.5, -Inf, NaN,
# -0.0, 0.0) is the source for the all-NaN, single-sample, and -0.0-sum
# fixtures the ticket calls for: a 30s window ending exactly on the NaN
# sample isolates it alone, a 7m window spanning the whole series exercises
# min/max's skip-unless-all-NaN rule end to end, and a 60s window ending on
# the last sample sums exactly the `-0.0`/`0.0` pair. `diff_boundary` (three
# samples 5m apart) supplies both a single-sample window and, queried
# entirely before `base_ts_ms`, a genuinely empty one (the matched series
# has no sample in range at all, so the whole result vector is empty).
#
# `mode: unordered` is correct throughout, for the same reason as
# selectors.txt (ADR-0021 decision 3).
