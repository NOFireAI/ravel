# Native-histogram function forms (docs/promql-evaluator-plan.md P11, #218).
#
# End to end since #218 stage 2: native histograms now flow ingest -> storage
# -> query -> evaluator on the Ravel side. `ravel_stack` ingests
# `dataset.histogram_series` through `IngestRouter::write_values`
# (`IngestValue::Histogram`), the RSEG v5 writer stores them, and ravel-query's
# histogram read path (#218 stage 1) serves them, so each query below produces
# a real Ravel result to diff against the pinned Prometheus binary. Confirmed
# by the first real `RAVEL_DIFFTEST=1` run (2026-07-30): histogram_count/_sum/
# _avg, the out-of-range quantile clamp, rate/increase over histograms, and
# sum/avg aggregation all match Prometheus bit-for-bit.
#
# Every query below reduces native histograms to float results so the existing
# bit-exact float comparator applies; raw histogram-valued results (a bare
# `diff_native_hist` selector, or `sum(diff_native_hist_agg)` without a
# `histogram_count`/`histogram_sum` wrapper) need a histogram-aware comparator,
# still deferred. Entries that would make Prometheus emit a warning/info
# annotation (mixed classic+native, float+histogram aggregation) are
# deliberately excluded: the comparator matches annotation presence, so such
# entries would mismatch on the annotation rather than the value. Those
# behaviors are pinned by ravel-promql unit tests instead
# (tests/histogram_native.rs) and listed in the P11 report.
#
# NOT float-precision residue after all. The P11 report flagged two suspected
# residues (bucket_bound arithmetic vs Prometheus' exponentialBounds tables for
# scale>0; add/sub without reconcileZeroBuckets). Neither surfaces in the real
# run: this dataset is schema 0 (so the scale>0 exponentialBounds table path is
# never taken) and the two aggregation series carry a uniform zero bucket (so
# reconcileZeroBuckets is a no-op). No ULP gap exists to measure, so ADR-0025's
# "no allowlist entry without numeric evidence" rule means no tolerance entry
# is added for either.
#
# FIXED (#252): histogram_quantile (interior phi) and histogram_fraction. The
# real run had shown a genuine evaluator semantic gap, not a float residue:
# Prometheus 3.13.1 interpolates within a native-histogram bucket
# exponentially, while Ravel interpolated linearly. ravel-promql now matches:
# it places the interpolated point on a log scale within the bucket
# (lower*(upper/lower)^within for the quantile, the log-ratio inverse for the
# fraction), and applies the same one-sided zero-bucket bound (lower/upper -> 0)
# to histogram_fraction that histogram_quantile already used. For the median of
# diff_native_hist at +0s (bucket (2,4], rank fraction 1/6) both now return
# 2*2^(1/6)=2.244924096618746; histogram_fraction(0,4,...) returns
# 6/7=0.8571428571428571 (rank_at(0)=0 via the zero-bucket bound, rank_at(4)=6).
# Those two queries are re-added below. The out-of-range-phi clamp stays too
# because it returns +Inf without exercising interpolation.
#
# Dataset: diff_native_hist{kind="counter"} is a monotonic counter native
# histogram (schema 0, three positive buckets, populated zero bucket).
# diff_native_hist_agg{i="1"|"2"} are two constant native histograms for
# aggregation.

name: native_histogram_count
query: histogram_count(diff_native_hist)

# FIXED (#1081): histogram_quantile/histogram_fraction now evaluate at a
# range-query top level (previously a typed rejection there). This is the
# literal canonical Grafana p99 latency panel shape --
# `histogram_quantile(0.99, <native-histogram-selector>)` with no wrapping
# arithmetic -- which was the first thing that errored against Ravel. The
# same expression nested in an arithmetic identity (`... * 1`) already
# evaluated; these entries pin the un-nested range form bit-exact against the
# pinned Prometheus binary, evaluated over a stepped grid (the whole call is
# recomputed fresh at each grid point and stitched into a matrix, exactly the
# generalization VectorMap/Instant already use). The step (60s) is a multiple
# of the 30s dataset step, so every grid point lands on a real sample, and
# 0.99 exercises the interior-bucket exponential interpolation the #252 median
# entry above already pins.
name: native_histogram_quantile_p99_range_grafana
query: histogram_quantile(0.99, diff_native_hist)
kind: range
start: +300s
end: +600s
step: 60s
mode: unordered

name: native_histogram_fraction_range
query: histogram_fraction(0, 4, diff_native_hist)
kind: range
start: +300s
end: +600s
step: 60s
mode: unordered
