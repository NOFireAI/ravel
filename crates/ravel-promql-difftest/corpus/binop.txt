# Native-histogram binary operators (#1700). Prometheus v3.13.1 defines a
# specific supported set over native histograms and drops-and-annotates the
# rest; Ravel now computes the same set with the FloatHistogram primitives and
# raises the same info annotation on the rest, instead of the old blanket 422.
# The supported set below was enumerated empirically against the pinned binary
# (operator x {histogram, float} on each side x {filter, bool}); this block
# pins every cell. `diff_native_hist` is the fixed dataset's native-histogram
# counter series (see histogram_native.txt); at +0s it has count 7, sum 12.
#
# The comparator matches the `infos` annotation channel by presence, so a
# drop-and-annotate cell is pinned as `expect: empty` (Prometheus and Ravel
# both answer empty and both raise an info). A supported filter comparison that
# simply does not hold also answers empty, but with NO annotation on either
# side; `hist_ne_two_histograms` below is that case, distinct from the
# annotated drops.
