- **The MCP compact text block escapes line separators, C1 controls and bidi
  controls in every caller string** (issue #3750). String cells, column names,
  the failure message, warnings and `next_steps` text now escape U+2028,
  U+2029 and the bidi controls U+202A to U+202E and U+2066 to U+2069 as
  `\u{XXXX}`, beside the control characters they already escaped. Map cells,
  the `# shared` line and each row's diff are serialized as JSON and then go
  through the same escape, so U+007F, U+0085 and U+009B no longer reach the
  text raw (`no_caller_path_writes_a_hostile_character_raw`). The `warnings:`
  line now quotes each warning and writes its `"` as `\"`, so a warning
  containing `; ` no longer reads as two
  (`one_warning_containing_the_separator_is_not_read_as_two`).
  `structuredContent` is unchanged.
