- **A series listing over objects that repeat the same series skips their
  catalogs.** `/api/v1/series`, `/api/v1/labels` and
  `/api/v1/label/{name}/values` over metrics now read each object's series
  ids first and skip the object's catalog decode when every id was already
  seen in an earlier object. A tenant whose series each appear in thousands
  of objects previously decoded every copy's labels and could run past the
  query deadline. An object that adds even one new series is still decoded in
  full.
