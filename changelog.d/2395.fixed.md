- **The shipped Query IAM template now grants what HTTP Parquet table DDL
  writes** (issue #2395). `deploy/iam/query.json` gains a create-only
  `s3:PutObject` on the table manifests (`QueryManifestCreate`, conditioned on
  `s3:if-none-match` `*`, so the role cannot overwrite an existing version),
  and `s3:PutObject` and `s3:DeleteObject` on the bucket probe's
  `sys/pq-probe/*` scratch objects; before this, every `CREATE EXTERNAL TABLE`
  and `DROP TABLE` over `POST /api/v1/sql` was refused on a per-role
  deployment (ADR-0055, HTTP DDL amendment).
