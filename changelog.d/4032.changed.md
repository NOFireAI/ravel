- The key-index leaf build now carries a re-encoded part's entries from every previous part with leaves whose hour range overlaps it, so a sealed day that a retention tombstone or a late record changes is rebuilt from its own previous leaves instead of from every entry's sections, and it fetches only each previous part's lowest leaf slice per field before the build starts, fetches each later slice when a build pass reaches it, and drops a slice once a pass starts past it, instead of holding every previous leaf for the whole build.
