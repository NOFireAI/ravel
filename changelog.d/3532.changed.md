- **The TypeScript SDK's kill-and-recover tests and demo kill a real worker
  process** (issue #3532). Worker A now runs as a child process that is sent
  SIGKILL inside a step, and worker B replays the steps, attempts and
  `EffectInDoubt` block the server recorded; a `manual` effect left in doubt
  is reconciled through `client.reconcile` with an `agents_admin` token. A
  new end-to-end test destroys an agent whose worker holds the turn and
  recreates it under incarnation 2. `createHttpTransport` no longer accepts
  the deprecated `journal` option.
