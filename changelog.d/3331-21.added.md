- **`ravel-cli agents` and the `ravel-agents-client` crate** (issue #3355).
  `agents dev` refuses the memory store before it does anything else, brings
  up the compose RustFS when the store does not answer, waits for its
  createbucket job, runs `store qualify`, and starts `ravel-server --agents`
  on loopback listeners with freshly generated development tokens, then
  prints the `agents scaffold` command. `agents scaffold <dir>` writes the
  TypeScript SDK's assistant example and refuses a non-empty directory.
  `agents list` (`--limit` above 1000 is refused, `--cursor` resumes),
  `inspect`, `operation`, `events` (cursor resume) and `effects` read HEAD
  straight from the bucket, with no server running. `agents reconcile`
  settles an in-doubt effect through a running server and needs an
  `agents_admin` token. Every command takes `--json`. `ravel-agents-client`
  is a Rust HTTP client over the `/api/v1/agents` routes with typed errors,
  long polls clamped to 20 s, and no retries.
