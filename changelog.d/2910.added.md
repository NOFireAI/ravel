- **`POST /api/v1/sql` runs a statement that joins signal tables.** A query
  can name two or more of `samples`, `logs`, `spans`, `alerts` and `audit`; it
  reads one snapshot per signal, with no ordering between them, and joins on
  the server that received it. `min_commit_token` on such a query, and a
  signal table beside a Parquet table, return a 400 saying they are not
  supported yet. A SQL alert rule may join signal tables the same way, so a
  join rule that failed on every evaluation now evaluates and can fire.
  Flight SQL and ES|QL still refuse a query naming two signal tables
  (ADR-2904).
