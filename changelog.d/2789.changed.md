- **Logs SQL row-path batches are built from the decoded block.** A logs
  scan that projects `attrs` (including `SELECT *`), runs under a pending
  erasure, or reads a block carrying an `attrs_raw` page now builds the
  `attrs` map, every `attrs['k']` column and every typed attribute column
  straight from the block's columns and each stream's resource and scope
  attributes, decoded once per stream in each block, instead of rebuilding
  a record and a merged attribute list per row. Erased rows are dropped
  before any column is built. Results are unchanged. The JSON stats object
  of `POST /api/v1/sql` adds `columnarBatches` and `rowpathBatches`, the
  output batches the logs scans built on each path (ADR-2773 decision D4).
