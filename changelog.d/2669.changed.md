- **The ingest write path runs its CPU-bound codec work on the write CPU gate**
  (ADR-1702 task 9). The metrics, log and span shard flush encodes, an OTAP
  payload's zstd decompression, an OTLP-HTTP gzip body's inflate and a Remote
  Write body's snappy decode now run on the blocking pool behind
  `--cpu-gate-write-permits`, under the `ravel_cpu_gate_jobs_total` sites
  `metrics_flush`, `log_flush`, `span_flush`, `otap_decode`, `otlp_http_gzip`
  and `remote_write_snappy`. A unit under the gate's 256 KiB inline floor still
  runs on the request or flush task and counts in
  `ravel_cpu_gate_inline_total`; a decompression is measured against the floor
  by its compressed size. Acknowledgement order, byte charges and stored
  objects are unchanged. If the gate returns no result, the unit fails without
  dropping anything: a flush answers its writers with the build error and
  counts in `ravel_ingest_abandoned_input_rejected_total`, an HTTP request gets
  500 or 503, and an OTAP batch is nacked on a stream that stays open.
