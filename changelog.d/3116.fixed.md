- **The `keyIndex` phase reports the bytes its KEY_IDX probe decodes.**
  `stats.phases` read `decompressedOutputBytes` 0 for `keyIndex` on every
  spans `trace_id` lookup and logs exact-key equality, beside real KEY_IDX
  reads. It now carries each probed object's KEY_IDX prefix (stored as is)
  plus every bucket frame it decoded, at the frame's declared length
  (`entry_count x 12`); request counts and wire bytes are unchanged. The
  logs probe that drops an object without planning it also now reads under
  the statement's cache access intent, as the keyed plan already did.
