- **S3 range and throttle classes no longer read echoed request text**
  (issue #2365). An object key or bucket containing "range" and
  "satisfiable" no longer turns a transient read failure into a permanent
  `InvalidRange`, and an error body that echoes a key containing "slowdown"
  or "timeout" no longer picks the throttle or timeout class when the body
  carries an S3 error code.
