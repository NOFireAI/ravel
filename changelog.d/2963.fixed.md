- **`ravel-cli sql explain` (the `sql-explain` build) fixes.**
  `--sql-partitions 0` is refused before any store request, as the server
  refuses a zero `--sql-partition-count`, instead of running with
  DataFusion's default of the host core count. A capped `--analyze` run
  prints `rows: <max-rows>+ (stopped at --max-rows)` instead of the
  cap-plus-one probe row as the count. `--start` equal to `--end` is
  accepted, matching `POST /api/v1/sql`; only `--start` after `--end` is
  refused.
