- **`GcsStore`, a read-write Google Cloud Storage backend in
  ravel-object-store (ADR-3456).** It uses the object's generation as the
  version token on every path, sends `x-goog-if-generation-match: 0` for
  create-if-absent and the expected generation for compare-and-swap, takes
  Application Default Credentials only, and counts its HTTP attempts into
  `ravel_store_attempts_total` and its responses' `Date` into the observed
  store time, as S3 does. It reports no multipart upload, no upload
  checksums and no bucket-protection probes. The contract suite runs against
  it on an in-process fake GCS endpoint in every run, and against a real
  bucket when `RAVEL_GCS_TEST_BUCKET` is set. Nothing selects it yet:
  `--store gcs` for ravel-server and ravel-cli follows in #3459 and #3460.
