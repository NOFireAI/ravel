- **Cached log string columns hand SQL their values without a copy.** With the
  decoded-column cache on, each cached string column keeps one Arrow values
  array over its own buffers, built once. A scan served from the cache, or
  the scan that admits the entry, now reuses that array instead of copying
  every cell: a plain column whose block no filter narrowed and whose rows
  are all present also skips the per-row key loop, and a block's own
  dictionary skips its per-scan values copy. Results are unchanged. The
  cache's memory reservation now lasts until the last Arrow buffer over an
  entry's bytes is gone, so the memory pressure evictor no longer counts as
  freed an entry a query result still holds. Each such entry is charged 512
  bytes more, and building the array counts once in `strCellsValidated`.
