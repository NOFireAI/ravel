- A two-level RLOG compaction now runs its second level on several range workers when its memory allows: the runs' streams are cut into ranges by a fixed record quantum, each worker merges a contiguous block of ranges under its share of the unit ceiling, and every worker count publishes the same parts. The level-1 and level-2 worker counts are derived together, each level-2 worker's read side counted against the ceiling; at the server defaults the derivation keeps one worker at each level, so those merges run as before. A range that would need more part-index slots than it owns is refused before that part is encoded, and the first failing level-2 worker stops the others before their next part write. The request report, the `rlog two-level merge` line and the `compaction merge ended` line carry `level2_workers` and `level2_ranges`, the last one also for a run without a request report.
