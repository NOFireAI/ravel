- **A page-directory chunk looked up only once no longer builds its block
  index** (epic #3231). The first lookup that reads a chunk scans its pages, as
  before the index existed, and the chunk's index, with the group tables that
  hold it, is built on its second lookup
  (`page_dir::index_tests::chunk_indexes_are_built_on_second_lookup`), so a
  point lookup that resolves each chunk once builds no index and no group table
  for it, only a one-byte lookup mark per chunk and an offset per group
  (`page_dir::index_tests::one_lookup_per_chunk_builds_no_index`). The
  dictionary-page lookup the reader makes for the same block uses a chunk's
  index only once built and never triggers a build
  (`page_dir::index_tests::chunk_indexes_are_built_on_second_lookup`). Results
  are unchanged
  (`page_dir::index_tests::index_matches_the_scan`).
