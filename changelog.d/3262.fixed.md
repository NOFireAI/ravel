- **A Parquet decoder error while scanning a file now fails the scan as corrupt, naming the file.** Previously some corrupt page headers and page bodies ended the scan in a bare decoder error, such as `EOF: eof decoding byte array` or `Required field type_ is missing`, that named neither the file nor the table. The error now carries `Parquet file <key>: the Parquet decoder failed while scanning table <table>:` ahead of the decoder's own message.
