- **`ravel_describe_data` pages a tenant with thousands of typed attribute
  columns.** An MCP cursor now carries a 32-byte digest of the tenant's typed
  attribute column set instead of the set itself, so its size no longer grows
  with the number of columns. Previously a page over 4,000 typed attribute
  columns minted a cursor of about 507 KB, over the 4 KiB cursor bound, and
  the call failed as `internal`. A changed set still expires the cursor, and
  the same columns in another order do not. Cursors move to version 6, so a
  version 5 cursor minted before the upgrade is refused as `cursor_invalid`.
