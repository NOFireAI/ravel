- **On a keyed bucket, an unkeyed `--remote-cluster` is refused at startup.**
  In all, gateway or query mode with a deployment key, durable `sys/auth`
  bearer tokens can onboard a tenant without a restart, so the federation
  startup guard now counts the coordinator as multi-tenant and requires
  `tenant=` on every `--remote-cluster`, even with a single `--tenant-token`.
  A `tenant=` naming a tenant known only through `sys/auth` is now accepted
  instead of refused as a mapping that can never fire.
