- **The MetricsBench stack runs s3s-fs `0.17.0-ravel.3`** (issue #2821).
  `ravel.2` is `ravel.1` plus `TCP_NODELAY` on every accepted connection.
  `ravel.1` held each response's body until the client acknowledged its head,
  which added a 40 ms delayed-ACK stall to every query that touched storage on
  the `ci` stack (issue #3561). `ravel.3` is `ravel.2` plus atomic conditional
  writes (issue #3652): `ravel.2` let concurrent create-if-absent or If-Match
  writers each succeed and could leave an object's body beside another write's
  stored checksum, which stopped a `cardinality` run before it ingested
  anything. `run.sh` now downloads `ravel.3` and checks it against its
  sha256s. Figures measured on one s3s-fs release are not compared with
  figures measured on another. The ClickBench entry still runs `ravel.1`.
