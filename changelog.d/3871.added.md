- **`ScratchStore`, a process-local scratch object store over a local
  directory** (#3871, ADR-3853 D2). It is the transient run store for the
  two-level RLOG merge: `open` empties the directory, `wipe` empties it
  again, and nothing in it is durable, published, or read by another
  process, so it must never back a tenant's data. Keys map to escaped file
  names that cannot leave the directory, puts are published by rename, and
  conditional puts, ranged and suffix gets, paginated listing and multipart
  uploads match `MemoryStore`. Nothing constructs it yet.
