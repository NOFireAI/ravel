- **The MetricsBench read-back counts by day windows and keeps a failed
  run's report** (issue #2821, issue #3330). `metricsbench_ingest` sums each
  read-back `count_over_time` over consecutive windows of at most one day
  instead of one query over the whole replay, which Prometheus refused with a
  422 on a 30-day replay, and records the window count per query in
  `readback.query_windows`. A failed read-back still exits non-zero, but the
  bin now prints the report for the rows replayed so far, the failed row
  carrying its mismatching `readback` or its query error in
  `readback_error`, so `ingest.json` keeps the ingest figures for diagnosis.
  `metricsbench_query` refuses such a report as a run result.
