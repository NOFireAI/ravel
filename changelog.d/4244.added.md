- **Ingest flushes can follow the `sys/compat` activation policy
  (ADR-4233).** A metrics, log or span router given an `IngestCompatPolicy`
  writes the format version the policy names, chosen when the flush gets its
  permit, fences the tenant's bucket before the first object above the
  baseline, and refuses to publish on a stale view, an active version this
  build cannot write, or a missing `sys/compat`. Refused writes return a
  retryable error and are counted by reason in `compat_publish_refused`.
  Without a policy, the only mode ravel-server runs today, flushes are byte
  for byte unchanged.
