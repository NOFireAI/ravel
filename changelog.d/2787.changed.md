- **SQL log scans build a declared string column's dictionary values once.**
  A string dictionary shared by a row group's blocks is decoded once and its
  Arrow values are built once per scan, however many blocks and 8192-row
  batches read it; each batch's declared `str` column is a slice of the
  block's keys over those shared values instead of a copy of the dictionary.
  A block whose string cells are stored plainly checks each cell's UTF-8 once
  and builds its values once, and a resource or scope value filling a missing
  cell is stored once per stream in the block. Results and the column's
  `Dictionary(Int32, Utf8)` type are unchanged. The SQL response's
  `stats.accounting.strDictValuesBuilt` and the `str_dict_values_built` scan
  metric in `EXPLAIN ANALYZE` count the values arrays built.
