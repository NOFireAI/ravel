- **A logs scan finds each block's pages through a per-chunk index** (issue
  #3231) instead of scanning every page of the block's row group in the page
  directory. The index is built in memory when PAGE_DIR is decoded and holds
  one entry per block that has pages in a chunk, never more than the chunk's
  page count, whatever block count the section declares
  (`page_dir::index_tests::index_size_follows_the_pages_not_the_block_count`).
  Resolving one block visits its own pages plus at most two per column chunk,
  after a binary search of at most `floor(log2(runs)) + 2` index entries per
  chunk (`page_dir::index_tests::block_pages_visits_only_the_blocks_run`), and
  returns the same pages in the same order as the scan
  (`page_dir::index_tests::index_matches_the_scan`). The object format is
  unchanged.
