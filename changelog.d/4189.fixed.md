- **The MCP SQL tools no longer return internal error detail when a result
  cannot be encoded as JSON.** An internal failure of the JSON encoding step
  (an Arrow writer error, a corrupt result column) used to be formatted with
  its `Display` into the tool failure, which could carry an object key or other
  server-side detail. The MCP surface now returns only the fixed, redacted
  client message, the same one the HTTP SQL surface returns, keeps the failure
  class internal, and logs the full error once with the tenant hash. A result
  whose column type has no JSON form still names the column, its type and the
  reason, unchanged.
