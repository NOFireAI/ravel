- **MetricsBench reads Ravel back on a folded catalog.** After the memory step,
  `deploy/metricsbench/run.sh` stops ravel-server, folds the metrics catalog
  with every writer stopped, starts the server again, and repeats the Ravel
  read-back. It fails the run when the folded read still spends catalog GETs
  at the unfolded rate, measured against the listed data-object count.
