- **ravel-cli accepts `--store gcs`.** A `ravel-cli` command that takes
  `--store` can run against a Google Cloud Storage bucket named by
  `--gcs-bucket` (`RAVEL_GCS_BUCKET`), with credentials from Application
  Default Credentials. `store qualify` records the bucket as
  `gs://<bucket>` (or `gs://<bucket>@<endpoint>`) in `sys/qualification` and
  passes `--list-page-size` to the GCS listing. Under `--store gcs`, these
  refuse with a non-zero exit before any request: `store verify-protection`
  (exit 2, no report, since it does not check GCS bucket protection),
  `--tenant-kms-config`, a `--s3-*` flag given on the command line or
  through its environment variable (a defaulted one is not refused), and
  `agents dev`, which drives the compose RustFS bucket.
