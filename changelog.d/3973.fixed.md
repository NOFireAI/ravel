- **`ravel-server`'s startup flag parse no longer needs a large stack.** In an
  unoptimized build one clap-derived function built every flag in a single
  stack frame of about 1.5 MiB, which left a test thread with the default
  2 MiB stack close enough to overflowing that adding one flag overflowed it.
  The flags are now split into groups and the parse fits on a 512 KiB
  thread. No flag's name, environment variable, default or help text
  changed; `--help` lists them in a different order.
