- **The catalog's decoded-part and postings caches can be bounded in bytes**
  (issue #3244). The new `decoded_cache_max_bytes` catalog setting caps the
  memory the two caches hold together, across every tenant, evicting the
  least recently used entries of either cache. A decoded object larger than
  the cap is not cached and is decoded again each time it is needed. The
  setting is unset by default; the server sets it to 1% of the process
  memory budget wherever that budget is finite.
