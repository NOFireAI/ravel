- **`metricsbench_ingest` takes `--anchor-ms` and streams its replay** (issue
  #2821). `--anchor-ms <i64>` fixes the first generated step's timestamp so
  two runs replay the same bytes, and the report records it as `anchor_ms`
  under `profile.run`. The flag is required, has no clock default, and exits
  64 when it is negative, off the profile's scrape grid, or puts the newest
  step past the nanosecond range. The replay now generates and sends one step
  at a time, so memory no longer grows with the step count. Every stream line
  is classified, and each row's `ingest` block carries `stream_counts` plus
  the named exclusions `excluded_native_histogram` and
  `excluded_stale_marker`; the run fails when those counts do not close
  against the generator's own figures or a line is malformed.
