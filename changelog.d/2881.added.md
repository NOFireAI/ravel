- **`ravel-cli sql explain` prints a statement's plan, and with `--analyze`
  the executed plan with per-operator metrics.** Each operator line carries
  its own `output_rows`, `elapsed_compute` and node-specific counters, and the
  run ends with the exact row count. The subcommand exists only in a
  `--features sql-explain` build and refuses to run without `--unaudited`,
  because it writes no query-audit record. The statement passes the same
  read-only gate as `POST /api/v1/sql`, which still refuses `EXPLAIN`.
