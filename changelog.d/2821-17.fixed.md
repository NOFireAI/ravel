- **A MetricsBench run whose Prometheus read-back fails now says it wrote no
  report** (issue #2821). `metricsbench_query --diagnostic-after-failed-ingest`
  refuses a run whose failed row is the Prometheus oracle's, since every other
  engine is classified against it. `run.sh` then ends at the query step with
  `failed_after_ingest: ["query"]` and runs neither validate nor the memory
  step. `memory-summary.json` is still written on the way out with every
  `--rss-band` checked, but a breach there is not listed in `stamps.json`. The
  closing message now says no `report.json` was written instead of calling
  one "not a result". Both MetricsBench READMEs, the `run.sh` header and the
  flag's help text describe this case.
