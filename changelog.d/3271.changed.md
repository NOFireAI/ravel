- **A `GROUP BY` on a declared `Str` column casts its key back to the
  dictionary type on the rows it returns, not on every group** (ravel-sql,
  ADR-0099 #3271 amendment). The `Utf8View` group key is now carried through
  the sort, merge, limit, exchange and renaming-projection operators above the
  aggregate, so under `ORDER BY <aggregate> LIMIT k` the cast runs above the
  TopK on `k` rows, and a two-level `COUNT(DISTINCT ..)` no longer casts the
  key back and forth between its levels. Result types, rows and order are
  unchanged. A `HAVING` filter, a join, a window or a union still reads the
  dictionary type from a projection below it.
