- **The Pod Identity sidecar's startup probe no longer passes on the file a
  previous sidecar process wrote.** The credentials volume outlives a sidecar
  restart, so the probe found the old file and passed before the new process
  had fetched anything. The sidecar now removes its written marker
  (`.credentials.json.written`) when it starts and creates it after each
  successful write, and the probe fails until the marker exists. The previous
  credentials file stays in place, so a running server keeps its credentials
  while the new process fetches.
