- **A logs exact-key equality probes KEY_IDX on every object above the
  block-range threshold** (issue #3117). The probe used to run only above the
  plan's whole-object bound, the larger of the threshold and the projection
  break-even, so under `cost-based` every object between the two was read
  whole, and one the scan left unplanned was opened whole without a probe.
  Such an object is now planned and probed, and dropped when a key is absent;
  one that holds the key, or whose keys all decline, is still read whole.
  An object at or under the threshold is read whole and not probed, as
  before.
