- **The word tokenizer no longer allocates per token** (ADR-3492 D4, issue
  #3495). `ravel_codec::tokenizer::for_each_token` yields each token as a byte
  slice from a stack buffer, with a byte-wise path for all-ASCII text, and
  `tokens` keeps its signature on top of it. Tokens and bloom bytes are
  unchanged, so written objects stay byte-identical.
