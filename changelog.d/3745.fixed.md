- **`stats.phases[].segmentsOpened` now counts on the logs and spans query
  paths** (#3745). Previously only the metrics RSEG fetcher and
  `ravel_get_trace` fed this counter; a logs SQL scan or a spans trace lookup
  always reported 0 for every phase. Each phase now reports the number of
  distinct data objects whose footer that phase opened, once per object,
  whether pruned afterward or not
  (`small_object_equality_opens_every_object_under_scan`,
  `key_indexed_equality_opens_every_object_under_plan_not_scan`,
  `trace_lookup_by_sql_opens_every_object_under_probe_not_scan`,
  `trace_lookup_by_get_api_traces_opens_every_object_under_probe_not_scan`,
  `a_window_outside_every_object_opens_nothing`).
