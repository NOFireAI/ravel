- **An integer average over a function of a declared string column runs
  exactly and in parallel again** (issue #2901). Since the move to
  DataFusion 55.2, `length(col)` and `octet_length(col)` over a declared
  string column can produce a dictionary-encoded integer, and `AVG` of such an
  argument fell back to a floating-point sum. That sum depends on the order
  rows are added in, so the statement lost its partitioned final aggregation
  and ran it on one partition, which made ClickBench q29
  (`AVG(length("Referer"))` grouped by a `REGEXP_REPLACE` of `Referer`)
  slower.
  `AVG` now uses the exact integer sum for these arguments, as it does for an
  integer column, so its result no longer depends on partitioning and the
  final aggregation is split across partitions again. A dictionary-encoded
  float GROUP BY key or `SUM`/`MIN`/`MAX` argument is treated as a float when
  deciding whether that split is safe, so it keeps the single-partition final
  aggregation.
