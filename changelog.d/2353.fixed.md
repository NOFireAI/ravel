- A store error is no longer classified as throttled or as a timeout because
  those words appear in the bucket, endpoint or object key of the request URI
  (issue #2353). The S3, GCS and Azure adapters now read the throttle and
  timeout class from the error text after the request URI, so an exhausted 500
  or a 400 against such a name stays `Transient` and keeps the caller's
  ordinary backoff, while a real 429, 503, `SlowDown`, `RequestTimeout`, 504,
  408 or transport timeout keeps its class.
