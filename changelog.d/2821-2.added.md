- **`metricsbench_ingest` records provenance and enforces band 4 per row**
  (issue #2821). `profile.run` gains `workload_version`, `workload_digest`
  (BLAKE3 over the manifest bytes), `seed` and `stream_digest`, and every
  row's `ingest` block gains `offered_digest`. `comparable` is now also false
  when the recorded stream digest differs from one regenerated from the
  manifest at the anchor. Each row must satisfy `offered +
  excluded_native_histogram + excluded_stale_marker == generated_lines` from
  its own fields, and each classified kind must equal the generator's count of
  it. A comparator row splits `dropped_samples` into `rejected_by_status`
  (samples per non-retryable HTTP status) and `retry_exhausted_samples`.
  Fields added since the nightly began load with defaults from an older
  report.
