- **`ravel-cli load` writes batches into a range of past ingest hours**
  (issue #3700). `--ingest-hour-stride <hours> --ingest-hour-start <unix
  hour>` writes batch i into ingest hour start + i x stride through a shifted
  clock, so a fresh tenant can span many ingest hours for read-path
  measurement (ADR-3692 decision 8). The lane forces one fully acked batch per
  hour, refuses with exit code 2 before any write on a tenant that already has
  a HEAD or commit records or when the range reaches the current hour, and
  names the synthetic hours in the load report. `ravel-cli catalog fold
  --snapshot-part-max-entries <n>` overrides the snapshot part cap for one
  fold, so a small cap gives hour-ranged parts.
