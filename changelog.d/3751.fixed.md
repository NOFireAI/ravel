- **A partial PromQL answer over MCP no longer reads as exact** (issue
  #3751). `ravel_query_promql` with `allow_partial_coverage: true` and a
  partial result now reports `accuracy.exact: false` with an approximation
  saying the result omits the data the query could not reach; before, only
  `coverage.partial` was set. The reference and guide now say that
  `accuracy.lower_bound_count` is reserved and always `false`, and that a
  `budget_exceeded` names its counter in `failure.message`, with
  `failure.counter` set only for the analyze-timeseries series cap.
