- **An `ORDER BY` over a spill-eligible aggregation can now spill** (ADR-0954
  amendment, issue #2416). Previously any `Sort` kept a query from spilling.
  When spill is enabled for such a query, its sort key gets the aggregation's
  `GROUP BY` columns appended as trailing tiebreak terms, ascending with nulls
  last, so rows tied on the requested order come back in the same order
  whether or not the query spills. A `Sort` over grouping sets, or over a
  projection that renames a group key, still keeps the query from spilling.
