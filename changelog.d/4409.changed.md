- **`ravel-cli load` writes RLOG pages with the exhaustive page choice by
  default again** (#4409). The estimated default from #4212 roughly doubled
  hot ClickBench Q24 and Q28 on c6a.4xlarge (#4388), and a load with
  `--page-choice exhaustive` restored them. `--page-choice estimated` stays
  available for a faster load, at the cost of slightly larger objects and
  slower reads of long URL-like string columns. Neither page-choice
  algorithm changes. A metrics or spans load now warns when `--page-choice`
  is set to `estimated` instead of `exhaustive`.
