- **The RLOG writer refuses a `stream_attrs` blob the reader cannot decode**
  (issue #2548). The writer validated each stream's blob with a walk that
  skipped the scope name and version unchecked, so a blob whose scope name was
  not UTF-8 was written and then refused by every reader of the merged view,
  failing the whole query for that segment. `stream_attr_pairs` is now built on
  the reader's decoder, so the writer refuses exactly what a reader would.
