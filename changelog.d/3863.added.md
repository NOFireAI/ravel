- **The fold can index metrics label names and values** (#3863, ADR-3694
  decision 2). With `ravel-cli catalog fold --key-index-leaves
  --metrics-label-index` (`CatalogConfig::metrics_label_index`, off by
  default) a metrics fold writes a `label_value` key-index leaf per part,
  keyed by every string in each object's LABEL_DICT at block 0, so a probe
  names the objects holding a label name or value. An object the fold
  already fetched for its name postings costs no extra GET; any other costs
  a footer suffix GET and one LABEL_DICT range GET. A part whose leaf would
  pass 1% of its objects' bytes (`metrics_label_index_max_ratio_ppm`) gets
  none, and while a metrics erasure request is pending no metrics leaf is
  built. `--rebuild-key-index --signal metrics --metrics-label-index`
  attaches the same leaf to existing parts. No query reads it yet.
