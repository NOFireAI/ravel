- **A keyed log or span write no longer stores a duplicate when its marker
  lookup is refused** (issue #2462). The gateway template in `deploy/iam/` now
  grants the list of exactly the idempotency-marker prefix a keyed write looks
  up, and a lookup the object store refuses now fails the write with a
  retryable 503 / `UNAVAILABLE` that writes nothing, instead of logging a
  warning and writing a second copy.
