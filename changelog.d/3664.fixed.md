- **`ravel_describe_data` no longer reports its row count as exact.** The
  `committed_rows` figure is summed from commit records, before duplicate
  collapse and before pending erasure, so it is an upper bound. Page one,
  the page that carries it, now reports `accuracy.exact: false` with an
  `accuracy.approximation` that says so; later pages still report
  `exact: true`. The `table` row drops `committed_rows_note`, which said the
  same thing, and the tool's catalog description now calls the count an
  upper bound instead of exact.
