- **The read cache admits by access intent.** `ravel-cache` gains
  `AccessIntent` (`Interactive`, `BulkScan`, `Maintenance`) and
  intent-taking variants of the RAM, tiered and S3-FIFO read and admit paths.
  A `BulkScan` read is admitted to a bulk region that keeps a fixed,
  hash-chosen subset of a repeated scan larger than the cache and never evicts
  the main queue, so an interactive hot set survives the scan. A bulk read the
  region declines is not copied into the cache. No production
  caller sets `BulkScan` until the SQL executor does in #3084, so this change
  leaves cache behaviour as it was. The caching guide now describes the
  caps as S3-FIFO rather than LRU (#2738).
