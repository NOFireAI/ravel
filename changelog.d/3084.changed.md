- **`--cache-bulk-scan-min-bytes <BYTES>` reads large filtered `logs` scans
  as bulk scans** (ADR-3072's size trigger amendment). It applies to `logs`
  statements sent as SQL text; default unset, which keeps the predicate-free
  rule alone. Set, a `POST /api/v1/sql` statement is also a bulk scan when it
  names one `logs` table and no Parquet table, its resolved segments sum to at
  least `BYTES` of object size before any read, and its optimized plan has no
  equality on a field the tenant indexes in KEY_IDX. Its reads then go to the
  fetcher cache's bulk region (`--cache-bulk-share`) instead of the
  interactive queues, and `stats.cache.intent` reports `bulkScan`. `samples`
  statements and lowered ES|QL statements are unaffected. Rows returned are
  unchanged.
