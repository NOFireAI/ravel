- **`--cache-bulk-scan-min-bytes <BYTES>` reads large filtered `logs` SQL
  scans as bulk scans** (ADR-3072 decision 3a, size trigger amendment). Unset
  by default, which keeps the predicate-free rule alone. Set, a `logs`
  statement sent to `POST /api/v1/sql` as SQL text is also a bulk scan when it
  names one `logs` table and no Parquet table, its resolved segments sum to at
  least `BYTES` of object size before any read, and its optimized plan has no
  equality on a field the tenant indexes in KEY_IDX. A `samples` statement and
  an ES|QL query never read as bulk through this rule. Its reads then go to
  the fetcher cache's bulk region (`--cache-bulk-share`) instead of the
  interactive queues, and `stats.cache.intent` reports `bulkScan`. Rows
  returned are unchanged.
