- **`-length(<Str column>)` plans again, and an integer average over a
  function of a declared string column takes its exact path again.** Under
  DataFusion 55.2, `length`, `char_length`, `character_length`,
  `octet_length`, `bit_length` and `ascii` over a declared `Str` column (a
  `Dictionary(Int32, Utf8)` column) returned `Dictionary(Int32, Int32)`, and
  `coalesce` of the column and an integer returned `Dictionary(Int32, Int64)`.
  So `SELECT -length("Referer") FROM logs` was refused with "Unary operator
  '-' only supports signed numeric, interval and timestamp types", and
  `avg(length("Referer"))` fell back to the Float64 average with a
  single-partition final aggregation instead of the exact integer average.
  These seven functions are now typed as the dictionary's value type and
  planned as a cast of their result, so these statements answer `Int32`
  again. The function still runs on the dictionary column, and output column
  names are unchanged (`length(logs.Referer)`). Every other function keeps
  its DataFusion type: functions returning strings, such as `lower`, keep
  their dictionary type, an explicit cast to a dictionary type is not
  rewritten, and a call built from SQL syntax such as `EXTRACT` still matches
  its by-name spelling in a GROUP BY (issues #2918, #2916).
