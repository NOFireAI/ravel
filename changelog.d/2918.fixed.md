- **`-length(<Str column>)` plans again, and an integer average over a
  function of a declared string column takes its exact path again.** Under
  DataFusion 55.2, `length`, `char_length`, `character_length`,
  `octet_length`, `bit_length` and `ascii` over a declared `Str` column (a
  `Dictionary(Int32, Utf8)` column) returned `Dictionary(Int32, Int32)`, so
  `SELECT -length("Referer") FROM logs` was refused with "Unary operator '-'
  only supports signed numeric, interval and timestamp types", and
  `avg(length("Referer"))` fell back to the Float64 average with a
  single-partition final aggregation instead of the exact integer average.
  Every scalar function whose result would be a dictionary of non-string
  values is now typed as that value type and planned as a cast of its result,
  so these statements answer `Int32` again. The function still runs on the
  dictionary column, output column names are unchanged
  (`length(logs.Referer)`), and functions returning strings, such as
  `lower`, keep their dictionary type (issues #2918, #2916).
