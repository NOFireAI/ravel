- **MetricsBench runs ADR-3694's remaining Stage 1 arms on an AWS box**
  (issue #3969). With `MB_STAGE1=1`, `MB_CONTROL_IMAGE` and
  `MB_CONTROL_SOURCE_COMMIT` (a digest-pinned image and its commit) run the
  unrouted pass again on that build and compare GETs, wire bytes and latency
  per statement and phase in `stage1-control-compare.json` (row 12).
  `MB_STAGE1_ARMS`, a comma list of `extra-hour`, `l1` and `erasure`, adds
  the arms that change the tenant: one more ingest hour folded twice from
  the same saved catalog HEAD, without and with leaves, stamping the wall
  ratio, the leaf bytes over the hour's data bytes and any uncovered part
  (row 7); `maintain compact-tenant` to L1, a leafy fold and a routed pass
  whose hashes must equal the routed pass's, with `fetch memory exhausted`
  records counted (row 6, #3818); and an erasure of
  `instance=metricsbench-instance-0`, a pending pass compared with a
  reference that excludes the subject, the rewrite run by a one-off
  `ravel-server --mode maintain` container, and the leaves still referenced
  over a rewritten hour (row 8). Each arm is stamped under `stage1.arms`,
  an arm that is off stamps its keys `skipped: arm off`, and 19 new figures
  in `stage1-bands.ci.json` are checked only when their arm ran, through a
  new `when` condition in `stage1-check.sh`. `aws/launch.sh` passes the
  switches to the measured run only; the nightly sets none (`run.test.sh`
  cases za, za1, zb to ze, zf1 to zf4, zg, zh, and the `stage1-check` arm
  cases).
