- **`metricsbench_ingest` waits for a receiver to make its writes queryable
  before reading them back** (issue #2821). A portable row's read-back that
  reads less than was sent is repeated every 500 ms for up to
  `--readback-settle-secs` (default 60, the same for every system), and each
  row's `readback` records `attempts` and `settled_after_ms`. Previously the
  first read was final, so VictoriaMetrics, which acknowledges a write before
  it is queryable, failed the read-back with zero series.
