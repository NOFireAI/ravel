- **The OTLP logs ingest path does less work per record (ADR-3492 D1, D2, D3a,
  D5, D6).** The logs flush picks each integer and string page's encoding
  from statistics instead of sealing every candidate (`ravel-cli load` still
  seals every candidate), and hands its buffered
  rows to the RLOG writer as one columnar batch, which writes the same object
  bytes as pushing the rows one at a time. Records under one OTLP scope share
  one stream-attribute blob, so a record with 40 string attributes costs 1
  allocation in normalization instead of 2. Stream admission decides each
  distinct stream once per request, with the same per-record outcomes and
  counters as before, and a record's buffered byte estimate is computed once
  instead of twice. The age-check tick is now
  `min(200 ms, --max-flush-delay / 4)`, no less than 25 ms: unchanged at the
  default 2 s delay, 25 ms at a 100 ms delay, where the
  `--idle-flush-byte-floor` hold is 175 ms longer.
