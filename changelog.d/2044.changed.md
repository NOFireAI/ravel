- **Queries wait for memory headroom at admission instead of failing their
  first fetch.** While the process memory budget's reserved bytes are at or
  above `--query-memory-admission-fraction` (default `0.75`, `0` disables)
  of its limit, a PromQL, metadata, SQL or Flight SQL query waits at
  admission, re-checking every 10 ms, and is refused with the existing 503
  `unavailable` (Flight SQL: `RESOURCE_EXHAUSTED`) and "query memory budget
  exhausted: no headroom freed before the statement deadline; retry" once
  its deadline would pass. The time waited comes out of the deadline. A
  running query's reservation growth never waits. The resolved fraction is
  logged on the `performance default resolved` line, and
  `ravel_memory_admission_waits_total` and
  `ravel_memory_admission_wait_refusals_total` count waits and
  refusals. A SQL fetch refused by the memory budget now answers "query
  memory budget exhausted: the process could not reserve memory to fetch
  segment data; retry" instead of "upstream storage temporarily
  unavailable"; status and `errorType` are unchanged, and the server's WARN
  line names the error variant.
