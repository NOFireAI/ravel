- **`ravel-cli load --decode-workers W` builds a logs load's decoded batches on
  W threads.** One thread still reads the `--read-cursors` cursors and deals
  every batch's rows in the same order; the builds run on W workers and the
  built batches reach the shard writers in the order they were dealt, so the
  objects written are the same at any W. Each batch is charged to
  `--load-memory-bytes` before its build starts, and the memory floor counts
  the cursor buffers each worker keeps alive. The default is one worker per
  four available cores, at least 1; `1` is the previous pipeline and `0` is
  rejected. Metrics and spans loads ignore the flag and warn. No wall-time
  effect is claimed here; epic #4203 measures it.
