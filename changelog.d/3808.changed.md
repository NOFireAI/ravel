- **Remote Write's acknowledgement mode is an operator flag, default
  buffered.** `ravel-server --remote-write-mode buffered|strict`
  (`RAVEL_REMOTE_WRITE_MODE`) sets the mode for every Prometheus Remote
  Write request, RW 1.0 and RW 2.0 alike. Under `buffered`, the default, a
  request is acknowledged after admission and enqueue, takes no
  `--max-pending-strict-acks` slot and carries no `x-ravel-commit-token`.
  Under `strict` a request is acknowledged after its commit record is stored,
  under `--strict-flush-policy`, as before. Remote Write still reads no
  `x-ravel-ingest-mode` header (ADR-2793, 2026-11-04 amendment).

  Upgrade note: Remote Write now acknowledges before durability by default.
  A Remote Write sender drops its WAL entry on any 2xx, so a Ravel process
  crash between the acknowledgement and the flush loses those points. Set
  `--remote-write-mode strict` to keep the old contract.
