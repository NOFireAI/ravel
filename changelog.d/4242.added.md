- **The RSEG, RLOG and RSPAN writers take the trailer version to emit.** RSEG's
  `_at` entry points take a `SegmentVersion`, and `RlogWriter` and
  `RspanWriter` take a new `WriteVersion` through `with_write_version`, which
  refuses any version outside the reader window. Writers not given a version
  emit the current one, byte for byte as before. A test-only `format-drill`
  cargo feature, off by default, adds a second version (the current bytes under
  trailer version N+1) so compatibility tests run against a two-version window;
  `scripts/guards/check-release-profile.sh` refuses it in every release-built
  path (ADR-4233 decisions 2 and 9).
