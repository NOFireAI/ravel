- **A high-cardinality `GROUP BY` with an exact integer `AVG` no longer holds several times the memory of the same query with `COUNT(*)`.** The exact integer `AVG` accumulator could not convert input rows to partial state, so partial aggregation never skipped on it and the emitted partial state sat in the exchange outside the SQL memory reservation. It now converts rows to state, and `skip_partial_aggregation` applies to it as it does to `COUNT` and `SUM` (issue #2488, follow-up of #2367).
