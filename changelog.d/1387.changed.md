- **The published `ravel-server` image now compiles in the MCP server.** The
  root `Dockerfile` builds `ravel-server` with
  `--features sql,flight-sql,otap,agents,mcp`, and the README support matrix
  gains a row for it. `POST /mcp` still mounts only with `--mcp`, in
  `--mode all` or `--mode query`, so a deployment that does not pass the flag
  serves nothing new. No `RavelCluster` field sets `--mcp` yet, so query pods
  the operator manages do not serve it.
