- **A SQL statement can join a Parquet table with a signal table.** A query
  on `POST /api/v1/sql` or Flight SQL may name Parquet tables beside any of
  `samples`, `logs`, `spans`, `alerts` and `audit`, for example `hits JOIN
  logs`, instead of being refused with a 400. The Parquet tables resolve
  first, then each signal table its own snapshot, and the statement's
  `max_s3_requests` and `max_bytes_scanned` budgets cover both. Flight SQL
  pins the Parquet manifests and the signal snapshots in the ticket, so a
  write to either between `GetFlightInfo` and `DoGet` is not visible. A
  `min_commit_token` bounds the signal tables only, and a token qualified
  with a Parquet table's name is a 400. A row window filters the signal
  tables only (ADR-2904 decision 11).
