- **The RLOG reader can evaluate a `LIKE '%needle%'` attribute filter on raw
  page bytes.** A new `Predicate::Contains` arm (with a negated form for
  `NOT LIKE`) tests each string cell of a plain, dictionary, or row-group
  dictionary page without building strings first, so a block where no row
  survives is never decoded. A cell that is absent or not valid UTF-8 reads as
  NULL and falls back to the stream's resource or scope value of the same key;
  a row whose attribute is another type is kept for the exact filter. The
  dictionary for a surviving block is built from the entries its survivors use
  and only those are UTF-8 validated, without filling the reader's shared
  dictionary cache. `ScanStats` gains `contains_cells_tested` and
  `str_cells_validated`. No SQL query constructs the arm yet.
