- **The log segment reader evaluates a `LIKE '%needle%'` predicate on a
  string attribute directly on the raw page bytes.** A dictionary page is
  tested once per entry and a plain page once per cell, without first
  validating every value as UTF-8; a cell whose bytes are not UTF-8 never
  counts as a match. A dictionary column the query only reads afterwards is
  validated for the entries the surviving rows reference, so a selective
  match validates at most as many cells as rows survive. Scan statistics
  report `contains_cells_tested` and `str_cells_validated`. Nothing in the SQL
  path builds the predicate yet.
