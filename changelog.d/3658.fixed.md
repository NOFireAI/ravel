- **`ravel_describe_data` fails on a failed metric metadata read instead of
  reporting no metric families.** A metrics call whose metadata record read
  failed now fails with the retryable class `unavailable` and a message saying
  the read failed, and so does every call the metadata cache serves from that
  failed read, until a read of the record succeeds. Previously the failure was
  answered as a page with zero families. A metrics tenant with no metadata
  record still answers an empty page, and now gives the reason in
  `families_absent_reason` and `warnings`.
