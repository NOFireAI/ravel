- **An RLOG compaction loads each input's catalog in one GET when the footer
  probe covers it** (#3855). The catalog load slices the footer, STREAM_DIR,
  FIELD_DIR, SKIP_IDX, PAGE_DIR, the key-index sections and the bloom-scope
  list prefix from the probe whenever a section's whole stored range lies
  inside it, and fetches only the rest by range. A two-input compaction of
  small objects now issues 2 catalog GETs instead of 10. The default
  `footer_probe_bytes` rises from 64 KiB to 128 KiB, for RSEG and RSPAN
  inputs too, so each input's first GET can return up to 128 KiB.
