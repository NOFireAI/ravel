- **The cost-based projection break-even is three request costs, not five**
  (issue #2555). A ranged read of a narrow projection was measured at about
  four GETs per object, so it pays when the bytes it skips exceed three
  request costs. On the reference profile the break-even is 18,900,000 bytes
  instead of 31,500,000, and the startup line reads
  `projection_break_even_bytes=18900000 break_even_source="profile"`; an
  object of that size or less still reads whole, and a 3 MB flush object is
  unaffected. An explicit `--logs-request-cost-bytes`, the other fetch
  policies, the coverage crossover and the coalescing gap are unchanged.
