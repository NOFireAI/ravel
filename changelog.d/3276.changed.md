- **`ravel-cli load --chunk-order` warns about a name the mapping carries
  only as a string or bytes resource attribute** (issue #3276). The RLOG
  writer gives such a key a column only when it is one of the tenant's
  indexed fields, which the load cannot know before it flushes, so a logs
  load now prints `warning: --chunk-order names <name>, a string resource
  attribute, which gets a column only if it is an indexed field` (or `a
  bytes resource attribute`) before it reads a row. A numeric resource key
  and a key also mapped as an `[[attribute]]` get a column and are not
  warned about.
