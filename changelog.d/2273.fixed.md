- **A server started through the library API refuses a zero loop interval**
  (issue #2273). `ravel_server::start` now refuses a zero fold, maintain,
  alert-evaluation or JWKS-refresh interval at startup, as the CLI already
  did, with a typed error naming the flag, instead of running that loop with
  no pause. For library callers, `fold::spawn` and
  `tenant::spawn_jwks_refresh` now return a `Result` carrying that error
  rather than the task handle directly.
