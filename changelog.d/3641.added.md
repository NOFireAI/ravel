- **The MCP server serves `ravel_describe_data`, its first cursor-paged
  tool** (epic #1374). For one signal (`metrics`, `logs` or `traces`) page one
  returns the table (segments, committed rows summed from commit records,
  event-time coverage window, family total), the fixed and typed attribute columns,
  the indexed keys and up to 100 metric families; later pages return
  families only. Families page by keyset on the name's bytes, so a later page
  starts strictly after the last name served
  (`describe_data_pages_families_by_keyset_through_the_route`). Every page of
  one sequence reports page one's watermark and snapshot id and resolves at
  page one's instant; a newer pending erasure on the same signal or a changed
  set of typed attribute columns expires the cursor and serves no rows
  (`a_metrics_cursor_survives_a_logs_erasure_and_expires_on_a_metrics_one`,
  `a_changed_declared_column_set_expires_a_logs_cursor`). `budget.actual`
  counts the catalog resolve only, and every page says so in `warnings`.
  Five tools are now served and four are catalogued.
