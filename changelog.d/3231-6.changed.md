- **`GROUP BY` on a declared `Str` column builds each dictionary's views once**
  (issue #3231). The cast of a `Dictionary(Int32, Utf8)` group key to
  `Utf8View` is now `DictionaryViewsCast`, which builds the views of a shared
  dictionary's values once and gathers each row's view by key, instead of
  re-reading every row's dictionary entry per batch. Its output is the one
  arrow's cast produces, view for view
  (`dictionary_views::tests::matches_the_stock_cast`), so query results do not
  change (`group_keys::tests::memoized_cast_answers_as_the_stock_cast`).
  `EXPLAIN` shows the group key as `DICTIONARY_VIEWS(<column> AS Utf8View)`
  where it showed `CAST(<column> AS Utf8View)`.
