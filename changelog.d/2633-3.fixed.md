- **A grouped aggregate's emitted output stays charged to the SQL memory
  pool while it is handed out** (issues #2633, #2720). DataFusion 54.1 shrank
  a grouped hash aggregate's reservation when it emitted, while the emitted
  batch still held those bytes, and the pool handed them to other queries at
  once. DataFusion 55.2's aggregate keeps the emitted batch reserved until
  its last slice is handed out, so those bytes count toward
  `--sql-max-query-bytes` and the tenant and process budgets until then. A
  shape DataFusion 55 still runs on its legacy aggregate, such as a
  single-stage `SELECT DISTINCT ... LIMIT`, still releases them early.
