- **The SQL memory pool keeps a grouped aggregate's released bytes charged
  until its stream ends** (issue #2633). DataFusion shrinks a grouped hash
  aggregate's reservation when it emits, while the emitted batch still holds
  those bytes, and the pool used to hand them to other queries at once. The
  pool now holds them on the query, tenant and process budgets until the
  aggregate's stream is dropped, which over-charges the aggregate until then.
  The hold is off when SQL spill is configured.
