- **OTLP logs normalization moves values out of the request instead of
  copying them.** Attribute keys, string and bytes values, severity text and
  a string body are taken from the decoded request, so a record with 40
  string attributes now costs 2 allocations instead of 84 (ADR-3492 D3a). The
  in-process `normalize_logs` entry point also sums the resolved-label
  projection in the same pass instead of walking the request first. Accepted
  records and refusals are unchanged.
