- **`spec.probes.dedicatedHealthPort` on `RavelCluster` now defaults to `true`.** New clusters, and existing ones that omit the field, now render the dedicated health listener (`--listen-health` on port 4316) and point both probes at it. This requires a `ravel-server` image that has `--listen-health`; an older image rejects the flag and restart-loops. Set `dedicatedHealthPort: false` to keep the previous render.
