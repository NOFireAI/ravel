- **Committed agent history now projects into logs and traces** (issue
  #3360, ADR-3331 decision 12). Each committed event becomes a log record
  and each committed turn a span, under a stable event id that is the same
  on every retry and restart, so the id is the deduplication key for
  queries. Payloads are redacted to a hash and a size unless the tenant is
  named by `--agents-projection-payload-tenant`. A process with an ingest
  buffer projects through its own ingest routers; `--agents-projection-endpoint`
  sends to an OTLP gateway instead, and `--agents` in a process with neither
  refuses to start unless `--agents-projection off` is given. A projection
  outage changes no agent state. `--agents-projection-backlog` bounds the
  undelivered records per tenant, and `GET /api/v1/agents/health` reports
  the projection mode, lag and delivery counters.
