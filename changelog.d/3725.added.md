- **The MCP server serves `ravel_search_logs`** (epic #1374), the last of the
  nine tools. Typed predicates (`eq`, `ne`, `in`, `exists`) on typed attribute
  columns and an indexed `trace_id`, a `has_word` body search, a minimum
  severity and a trace id compile to one `SELECT` over `logs`, with every
  caller value rendered as a quoted literal
  (`caller_values_reach_the_statement_only_as_literals`,
  `search_logs_filters_and_pages_a_logs_tenant`). A predicate key that is
  neither a typed attribute column nor an indexed key is refused before any
  statement runs, with a next step naming `ravel_describe_data`
  (`an_unknown_key_is_refused_before_the_statement_runs`). Results order and
  page by `(ts, observed_ts)`, and a page never ends inside a group of rows
  equal on that pair (`a_group_straddling_the_cap_is_not_split`); a group
  larger than the page comes back `ok_bounded` with no cursor
  (`a_group_larger_than_max_rows_is_bounded_with_no_cursor`). Rows with the
  same attribute key set form a group, and the attributes the whole group
  shares are listed once in `group_attrs`
  (`shared_attributes_are_hoisted_once_per_group`). An `evidence_ref` is
  refused as `unsupported`. All nine tools are now served and none is only
  catalogued.
