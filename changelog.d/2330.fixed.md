- **A server started through its library API refuses a zero store-probe,
  admission-reconcile or scrub interval, and a zero fold-lag interval, at
  startup** (issue #2330). The three intervals used to start a loop that ran
  back to back, and the fold-lag interval classified fold lag against a fold
  no maintain tier runs; `start` now returns a typed error naming the flag
  (`--store-probe-interval`, `--admission-reconcile-interval`,
  `--scrub-period`, `--fold-lag-interval-secs`) before it spawns a task or
  makes a store request, matching the refusals the command line already
  applied.
