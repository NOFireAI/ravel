- **The ingest router refuses a zero JWKS refresh interval at startup**
  (issue #2330). Started through its library API, the router used to panic
  the refresh task on a zero interval and tear itself down; `run` now
  returns `JwksRefreshSpawnError::ZeroRefreshInterval`, naming
  `--oidc-jwks-refresh-interval-secs`, before it builds a Kubernetes client
  or spawns any task. The CLI already refused a zero value.
