- **`ravel-server --format-window-check {warn|refuse}` reports catalog entries
  outside this build's reader window at startup (ADR-2708 D5c).** For each
  statically known tenant (`--tenant-token`, `--tenant-token-file`,
  `--maintain-tenant`, `--alert-rules-file`) and each of metrics, logs, spans,
  alerts and audit, the server reads the catalog HEAD and its snapshot parts
  and counts entries whose recorded format version the readers would refuse.
  `warn`, the default, logs one line per (signal, version) with the count and
  starts; `refuse` exits non-zero before any listener binds, naming the signal
  and version. A store error is reported as a check that could not run, and
  `refuse` exits non-zero on it. The check costs one GET per tenant and signal
  plus one per snapshot part, and issues no LIST, so commit records not yet
  folded are not checked. See "Format crossings at startup" in the
  maintenance guide.
