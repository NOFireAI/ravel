- **No MCP failure carries an internal error's text to the caller.** A failed
  `ravel_analyze_timeseries` analytic used to format the analytics error into
  its `internal` failure, and a result envelope that could not be serialized
  returned the serializer's error as `data.reason`. Each now returns a fixed
  message under the same class (the serialization error with no `data` at all)
  and logs the full error once at warn with the tenant hash. A new gate check
  refuses an MCP failure constructor whose arguments are formatted text unless
  a reasoned marker shows it only echoes caller input or fixed values.
