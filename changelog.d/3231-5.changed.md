- **A decoded-cache hit on a plain `Str` column no longer re-validates its
  cells** (ADR-3326 decision 5 and its validation-state amendment, issue
  #3231). A plain page of a `Str` attribute column that no `LIKE` contains
  arm tests is UTF-8 validated once at decode and kept as text when every
  cell is UTF-8, so the columnar build and a later cache hit read each cell
  as a slice. `strCellsValidated` now counts those cells once, at decode, and
  a statement served from the cache counts none of them. A page with a
  non-UTF-8 cell reads and counts per cell as before.
