- **The server log keeps the cause of a SQL error that crossed a repartition.**
  When a query failed below a `RepartitionExec`, the error the server logged
  carried only the redacted client message ("upstream storage temporarily
  unavailable" and the like), so the object key and the backend's own error
  text were lost. The logged error now prints the original error's full text.
  The message sent to the client is unchanged and stays redacted.
