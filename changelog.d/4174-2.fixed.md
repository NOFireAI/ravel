- **A SQL query error that crosses a repartition keeps its cause in the server
  log.** DataFusion hands such an error to every output partition behind a
  shared reference, and the error Ravel rebuilt from it printed only the
  redacted client message, so the server's "sql query error redacted from
  client response" line carried no object key or storage cause. The rebuilt
  error now logs the original error's full text. The client response is
  unchanged.
