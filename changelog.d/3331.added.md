- **Ravel Agents contracts land as `ravel-agents-core`** (issue #3331). The
  new `proto/ravel/agents.proto` defines the per-agent `AgentHead` root and
  the eight immutable objects it references, each at `format_version` 1 and
  sealed. The crate holds the `t/<tenant_hash>/ag/<agent_id>/` key layout,
  agent and minted-id hashing, the HEAD codecs, typed commands and errors,
  a pure transition kernel in which a turn commit publishes the new state,
  the consumed input, its result, events and effect intents in one root,
  and the HTTP wire types, with JSON fixtures under `sdk/fixtures/`.
  `ravel-agents-store`, `ravel-agents-runtime`, `ravel-agents-client` and the
  dev-only `ravel-agents-sim` are empty skeletons. Nothing on the server
  calls any of them yet, so no request path or stored format changes.
