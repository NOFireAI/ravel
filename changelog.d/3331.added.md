- **Ravel Agents contracts land as `ravel-agents-core`** (issue #3331). The
  new `proto/ravel/agents.proto` defines the per-agent `AgentHead` root and
  eight immutable object types, each at `format_version` 1 and sealed. At
  version 1 HEAD keeps its lists inline and references only the
  `StateSnapshot` (plus payload objects); the seven page, transcript,
  journal and table objects belong to the paged representation, which
  version 1 refuses. The crate holds the `t/<tenant_hash>/ag/<agent_id>/`
  key layout, agent and minted-id hashing, the HEAD codecs, typed commands
  and errors, a pure transition kernel in which a turn commit publishes the
  new state, the consumed input, its result, events and effect intents in
  one root, and the HTTP wire types, with JSON fixtures under
  `sdk/fixtures/`. Every `*_unix_ns` wire field is a decimal string, since
  a JSON number loses precision past 2^53.
  `ravel-agents-store`, `ravel-agents-runtime`, `ravel-agents-client` and the
  dev-only `ravel-agents-sim` are empty skeletons. Nothing on the server
  calls any of them yet, so no request path or stored format changes.
