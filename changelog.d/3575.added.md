- **A principal can carry a subject** (issue #3575, ADR-3541 decisions 1 to
  3). A static bearer token's capability list accepts one `subject=LABEL`
  entry, a label of 1 to 64 bytes from `A-Z a-z 0-9 . _ @ + -`, beside or
  instead of the capability words; a malformed or repeated entry refuses
  startup. The OIDC resolver can read the subject from a configured claim of
  the verified token, leaving it absent and counting the drop when the claim
  is missing or not a bounded printable string. A subject grants nothing, and
  nothing records it yet: issues #3576 and #3577 write it into the agents and
  query audit records. A tenant whose own last `;` segment is `subject` or
  starts with `subject=` now refuses startup, so a pair such as
  `tok=acme;subject=x;ddl`, which used to name tenant `acme;subject=x`,
  refuses instead.
