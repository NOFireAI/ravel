- **`ravel-cli load` writes RLOG pages with the estimated page choice by
  default.** The new `--page-choice exhaustive|estimated` flag selects how the
  writer picks each page's encoding; `estimated` seals one candidate picked
  from the page's statistics instead of sealing every candidate and keeping
  the smallest, and `--page-choice exhaustive` restores the previous
  behaviour. On the ClickBench entry load (c6a.4xlarge, #4203 comment
  6900891749), `estimated` cut load wall from 490.1 s to 452.4 s (7.7%) and
  load CPU by 11.1% for 2.43% more l0 bytes (8,530,539,390 against
  8,328,210,617); cold Q21, Q28 and Q29 on an estimated tenant were within
  0.1 to 2.6% of the exhaustive one (#4203 comment 6883696111). No format
  change: readers decode objects from either choice the same way. The load
  summary's `page choice` line and the report JSON's `page_choice` field name
  the choice used (ADR-4203 decision 7).
