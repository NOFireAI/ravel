- **The read cache serves part of a repeated scan larger than itself.**
  Previously a hot query run over more objects than the cache held was
  served nothing from it on every repeat, because no entry stayed resident
  from one run to the next. Now the first run fills the cache and the
  second and third runs read the same subset from it: 45% of the bytes for
  equal-sized objects at twice the cache's size, 81% when the cache holds
  90% of the scan. A new
  repeated scan that starts after another one filled the cache converges
  the same way. One that starts right after a one-pass scan three times its
  size filled the cache converges a run later, from its third run, if it is
  at most about twice the cache's size; a longer one is not served.
