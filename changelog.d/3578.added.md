- **The mTLS listener can name the caller in query audit records** (issue
  #3578, ADR-3541 decision 3). `--mtls-subject-header <HEADER>` names a second
  proxy-forwarded header; on the `--mtls-listener` chain only, its value is
  recorded verbatim as `query.principal.subject` with source `mtls`. The value
  must be 1 to 255 bytes of printable ASCII with no space, so the proxy should
  forward an email or URI SAN, or a single CN without a space; anything else
  leaves the subject absent and counts on
  `ravel_auth_subject_dropped_total{source="mtls"}`. Startup refuses the flag
  empty, without `--mtls-enabled`, naming the tenant header, or when the value
  is not a valid HTTP header name.
