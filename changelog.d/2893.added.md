- **ES|QL over `POST /api/v1/esql`, behind the `esql` cargo feature.** The
  route runs one ES|QL statement over the `logs` table (`FROM logs` or `ROW`,
  with `WHERE`, `EVAL`, `KEEP`, `DROP`, `RENAME`, `STATS ... BY`, `SORT` and
  `LIMIT`) and answers with typed columns, rows, the same `stats` sections as
  `/api/v1/sql`, and `warnings` when a `LIMIT` above 10,000 was lowered. A
  statement that does not end in `LIMIT` returns at most 1,000 rows. Anything
  outside the subset is refused with a typed 400 naming the construct and its
  line and column; a planning failure, or a time window wider than the
  catalog serves, is a 422. It shares the SQL surface's admission ceiling,
  deadline clamp, usage accounting and query audit, which records it with
  `query.language = esql` and redacts string literals, value numbers and
  `PROMQL` parameter values to the same tokens SQL and PromQL use. The
  feature turns on `sql`, and the published image does not include it.
  `scripts/gates.sh` and CI gain an `esql` clippy and test lane, and
  `scripts/affected-tests.sh` runs `-p ravel-server --features esql` when
  ravel-server is in the closure.
