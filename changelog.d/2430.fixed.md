- **A forged Parquet table manifest version can no longer wedge a table**
  (issue #2430). Manifest versions are bounded at 2^32: DDL refuses to write a
  version above it with a 422, queries and DDL ignore any version above it
  and log a warning naming the table, `ravel-cli parquet sweep` neither
  deletes nor counts it, and
  `ravel-cli parquet repair --tenant <t> --table <name> --delete`, run under
  the Maintain credential, deletes exactly those versions.
