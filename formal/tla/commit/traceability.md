# Traceability: commit protocol model to Rust

Every row names the Rust that performs or asserts the transition, and says
whether Rust does it atomically or the model assumes a helper or the backend
does. Paths and symbols only, never line numbers. The third column carries one
resolved reference; further references sit in the meaning column, where the
harness resolves them too.
