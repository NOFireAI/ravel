# Correct-form counterexamples

No correct-form configuration (`MCSpec`/`MCFairSpec` with every switch at its
default) produced a counterexample. Every counterexample this area records is a
negative control -- a single flipped constant -- and its prose walk lives under
`../negative/counterexamples/`. This directory is reserved for a walk of any
counterexample TLC finds in a correct-form model; there are none.
